# Changelog

## [0.1.0] - 2026-11-24

- Initial MIT release of `brepmass` C99 library, CLI, and Python `ctypes` wrapper.
- Exact divergence-theorem closed-mesh integrals & open-shell surface integrals (`dim=2`).
- Directed half-edge watertightness check & Euler characteristic `V - E + F`.
- Parallel-axis centroid inertia shift & cyclic Jacobi principal moments/axes solver.
- Closed-form analytic references (`box`, `cylinder`, `cone_frustum`, `sphere`, `torus`).
- Tessellators for primitives, 2D polygons with arbitrary holes (ear-clipping), and rational/non-rational NURBS patches.
- Binary/ASCII STL (with spatial-hash vertex welding on read) and Wavefront OBJ I/O.
- Added multilingual READMEs (EN, RU, ZH-CN, DE, JA, ES), SVG logos, social preview banner, and GitHub release workflow.
