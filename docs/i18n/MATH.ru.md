# Математические формулы `brepmass`

Краткий вывод расчётных соотношений, реализованных в `src/mass.c` и `src/tessellate.c`.  
([English version](../MATH.md) · [Вернуться к README](README.ru.md))

## 1. Объём и моменты замкнутого тела (теорема Гаусса–Остроградского)

Для водонепроницаемой ориентированной триангуляции с обходом треугольников $(\mathbf{a}_k, \mathbf{b}_k, \mathbf{c}_k)$ каждый треугольник образует сориентированный тетраэдр с началом координат $(0, \mathbf{a}, \mathbf{b}, \mathbf{c})$:

$$v_k = \frac{1}{6}\, \mathbf{a} \cdot (\mathbf{b} \times \mathbf{c})$$

Суммарный объём $V = \sum_k v_k$. Пусть $\mathbf{S} = \mathbf{a} + \mathbf{b} + \mathbf{c}$. Тогда:

- **Первый момент и центр масс**:
  $$\mathbf{M}_1 = \sum_k \frac{v_k}{4} \mathbf{S}, \qquad \mathbf{c} = \frac{\mathbf{M}_1}{V}$$
- **Второй момент (ковариационный тензор)** $C_{ij} = \int \rho\, x_i x_j\, dV$:
  $$C_{ij} = \rho \sum_k \frac{v_k}{20}\left(a_i a_j + b_i b_j + c_i c_j + S_i S_j\right)$$

## 2. Тензоры инерции и главные оси

При массе $M = \rho V$ и центре масс $\mathbf{c}$:

- **Тензор инерции относительно начала координат**:
  $$I_0 = \operatorname{tr}(C)\, I_3 - C$$
- **Тензор инерции относительно центра масс (теорема Штейнера)**:
  $$I_{\text{cm}} = I_0 - M \left(\|\mathbf{c}\|^2 I_3 - \mathbf{c} \otimes \mathbf{c}\right)$$
- **Главные моменты и главные оси**: вычисляются циклическим методом вращений Якоби для вещественной симметричной матрицы $3 \times 3$ $I_{\text{cm}}$ и сортируются по возрастанию $I_1 \le I_2 \le I_3$.

## 3. Интегралы открытой поверхности (`dim = 2`)

Если не все направленные полурёбра имеют парные противоположные, `brepmass` вычисляет поверхностные интегралы по площади каждого треугольника $A_k = \frac{1}{2}\|(\mathbf{b}-\mathbf{a})\times(\mathbf{c}-\mathbf{a})\|$:

$$\int \mathbf{x}\, dA = \sum_k \frac{A_k}{3}\mathbf{S}, \qquad \int x_i x_j\, dA = \sum_k \frac{A_k}{12}\left(a_i a_j + b_i b_j + c_i c_j + S_i S_j\right)$$

## 4. Эталон для усечённого конуса

Для $z \in [0, h]$ с нижним радиусом $r_1$ и верхним $r_2$:

- $V = \frac{\pi h}{3}(r_1^2 + r_1 r_2 + r_2^2)$
- $z_{\text{cm}} = \frac{h}{4}\frac{r_1^2 + 2r_1 r_2 + 3r_2^2}{r_1^2 + r_1 r_2 + r_2^2}$
- $I_{zz} = \rho\frac{\pi h}{10}(r_1^4 + r_1^3 r_2 + r_1^2 r_2^2 + r_1 r_2^3 + r_2^4)$ (без особенности при $r_1 = r_2$)
- $I_{xx,0} = I_{yy,0} = \frac{1}{2}I_{zz} + \rho\pi h^3 \left(\frac{r_1^2}{30} + \frac{r_1 r_2}{10} + \frac{r_2^2}{5}\right)$
